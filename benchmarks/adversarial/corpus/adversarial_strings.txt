# Adversarial string seed corpus.
#
# Each entry is a string the harnesses should be fed as a deliberate
# edge-case test. The harnesses ALSO generate random adversarial inputs on
# the fly via their inline generators; this file is the canonical
# hand-picked set of edge cases that captures the full threat-model surface
# enumerated in cycle_67/adversary/01 (VULN_AUDIT.md §3).
#
# Format:  python_repr|category|expected_behavior
#
# Lines starting with "#" are comments. The harness loaders strip comments.
# Each non-comment line is a single repr-decodable Python string + a
# category label + an expected behavior tag.
#
# Expected behaviors:
#   VALIDATE_FALSE   validate() MUST return False (never raise)
#   FORMAT_OK        format_display() MUST succeed (return str)
#   COMPUTE_RAISE    compute_check_digits() MUST raise ValueError
#                    (for too-short or non-alnum str inputs)
#   ANY              no contract; harness counts outcome
#
# Categories (one per line):
#   EMPTY            empty string ""
#   WHITESPACE_ONLY  strings of only whitespace ("   ", "\\t\\n", " " * 100)
#   SHORT            boundary strings 1..4 chars (below validate's 5-char floor)
#   LONG_VALID_LEN   90-char alphanumeric (just under 100 cap) — not IBAN, must reject
#   LONG_OVERSIZE    101, 200, 1000, 10000, 100000 char strings (above 100 cap)
#   UNICODE_BMP      CJK, RTL/LTR markers, BOM, NBSP, replacement char
#   UNICODE_LATIN    É, ñ, ü (passes isalnum but is non-ASCII)
#   CONTROL_CHARS    \\x00..\\x1f, \\x7f
#   PUNCTUATION      all-punctuation strings (5..50 chars)
#   CONCAT_BORDERLINE one-char-prefix/suffix + valid IBAN (alnum but wrong length)
#   DOMAIN_MISMATCH  looks-like-IBAN but first 2 chars are not a real country code
#
# NOTE on categories that are NOT here:
#   MIXED_CASE       — lowercase real IBAN (e.g. "de89...") is NOT adversarial;
#                      validate() is documented to accept it (case-invariant).
#   WHITESPACE_PADDED— "  DE89...  " is NOT adversarial; validate() is documented
#                      to strip spaces + hyphens before checking.
#   HYPEN_SPACED     — "DE89-3704-..." is NOT adversarial; same stripping rule.
# Those categories are covered by harness_inline generators but excluded
# from the corpus because they belong to the contract, not the threat model.
#
